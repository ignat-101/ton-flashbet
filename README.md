# TON FlashBet — Ставки на ВСЁ

Моментальные ставки на любые события через Telegram и TON. Без смарт-контрактов, только Python и бесплатные API.

## 🚀 Быстрый старт

1. **Клонируй и установи зависимости:**
   ```bash
   git clone https://github.com/ignat-101/ton-flashbet.git
   cd ton-flashbet
   pip install -r requirements.txt
   ```

2. **Настрой .env:**
   Создай файл `.env` в корне:
   ```env
   BOT_TOKEN=твой_токен_от_@BotFather
   BOT_USERNAME=FlashBetTON_bot
   TON_API_ENDPOINT=https://toncenter.com/api/v2/jsonRPC
   BOT_WALLET_ADDRESS=твой_кошелек_TON
   ```

3. **Запусти бота:**
   ```bash
   python bot.py
   ```

## 📋 Команды

| Команда | Описание |
|---------|----------|
| `/newbet @user 1.0 "BTC > 100k"` | Создать спор с конкретным человеком |
| `/openbet 5.0 "Снег в Москве"` | Открытая ставка (любой может принять) |
| `/pay bet_12345 <hash>` | Подтвердить оплату ставки (хеш транзакции) |
| `/won bet_12345` | Заявить о победе |
| `/mybets` | Показать мои активные ставки |

## 💡 Как это работает

1. **Создание:** Игрок А создает ставку. Бот генерирует уникальный `bet_id`.
2. **Оплата:** Оба игрока отправляют TON на кошелек бота с комментарием `bet_id`.
3. **Активация:** Бот проверяет транзакции через бесплатный TON API.
4. **Результат:** 
   - Если ставка про курс — бот сам проверяет цену через CoinGecko.
   - Если событие — работает система «заявление + таймер + голосование».
5. **Выплата:** Победитель забирает банк (минус 0.1 TON комиссия бота).

## 🔥 План продвижения (Бюджет $30)

1. **День 1:** Создай 5-10 фейковых ставок на крупные суммы в крипто-чатах.
2. **День 2-3:** Закупи 3-4 поста в `@ton_ru`, `@crypto_p2p` ($20).
3. **День 4+:** Виральность через кнопку «Принять ставку» в группах.

## ⚙️ Настройка для продакшена

- **Хостинг:** Pella.app (бесплатно для Python-ботов) или Vercel.
- **База данных:** Сейчас JSON (`storage.json`). Для нагрузки замените на SQLite/PostgreSQL.
- **Кошелек:** Сгенерируй новый кошелек специально для бота (через TonKeeper или код).
